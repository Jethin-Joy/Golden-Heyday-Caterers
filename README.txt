GOLDEN HEYDAY CATERERS — SINGLE-PAGE WEBSITE

This is a responsive, single-page static website. All main content is in index.html.
Navigation links scroll to sections on the same page.

FILES
- index.html       Main single-page website
- styles.css       Responsive styling
- script.js        Mobile navigation and WhatsApp enquiry form
- images/          Supplied website photography

PREVIEW
Open index.html in a web browser. No build step or server is required.
